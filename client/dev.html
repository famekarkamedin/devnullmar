Gateway URL

wss://api.nullmarket.com/gateway?token=BOT_TOKEN&intents=["GUILD_MESSAGES"]

Замените BOT_TOKEN на токен вашего бота. Поддерживаемые intents: GUILDS, GUILD_MESSAGES, DIRECT_MESSAGES, COMMANDS, GUILD_MEMBERS, MESSAGE_REACTIONS, PRESENCE_UPDATE, VOICE_STATE

Пример подключения

// Подключение к Gateway const ws = new WebSocket('wss://api.nullmarket.com/gateway?token=BOT_TOKEN'); ws.onopen = () => { console.log('Подключено к Gateway'); }; ws.onmessage = (event) => { const payload = JSON.parse(event.data); if (payload.op === 1) { // Отвечаем на heartbeat ws.send(JSON.stringify({ op: 2 })); } };
